# Experiment 002: Prompt Engineering

## 目的

理解 prompt 写法对模型输出的影响。

## 常用技巧（对比维度）

- Zero-shot：直接提问
- Few-shot：在 prompt 里给几个输入/输出示例
- Chain-of-Thought（CoT）：要求模型"一步步思考"
- 角色设定：用 system prompt 指定身份/风格
- 输出格式约束：要求以固定格式（如 JSON）输出
